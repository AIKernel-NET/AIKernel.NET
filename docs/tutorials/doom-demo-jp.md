# Doom デモのチュートリアル

1. [公式サイトの埋め込みデモ](https://aikernel.net/#doom-demo)を開きます。
2. 利用規約とライセンス表示を読み、ダウンロードに同意する場合だけ GPU または CPU モードを選びます。
3. 読み込み後に Start または実行コントロールを操作します。GPU が利用できない場合や VRAM が少ない場合は CPU モードを使います。

## デモのバージョン

配置候補では `/demo/doom/` が一覧です。反映後は承認済みの各版を `/demo/doom/versions/v<version>/` に置き、JS・Worker・WASM・プロファイルを版ごとに分けます。初回の候補は既存の `v0.1.2` のみで、`v0.1.3` はローカルプレビューです。WAD とモデルは共通の配信先から同意後に取得します。
